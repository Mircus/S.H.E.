# DBLP Score Phase

This directory records the earlier score-centric DBLP phase.

Scope of that phase:

- edge-level future-support prediction
- bridge-emergence experiments
- triangle branching experiments
- score-family comparisons across SDM and WSDM

Why it is archived:

- it established useful infrastructure
- it did not yet yield the aggregation-life-cycle view now needed for the
  psychohistory program

The active research direction has moved to `seldon-lab/`, where aggregation
ontology, identity tracking, and transformation events are first-class objects.
