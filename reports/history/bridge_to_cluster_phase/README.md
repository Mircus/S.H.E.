# Bridge-to-Cluster Phase

This directory records the bridge-to-cluster phase that followed the generic
future-support experiments.

Scope of that phase:

- explicit bridge-like edge candidates
- edge-to-triangle expansion targets
- binary triangle emergence targets
- bridge-to-cluster score family and cross-venue evaluation

Why it is archived:

- it sharpened the structural question
- it did not yet produce a decisive geometry-field win
- it exposed the need for a broader aggregation ontology rather than another
  score contest

The next layer is now developed in `seldon-lab/`, where birth,
reinforcement, decay, and later fusion/fission are treated as transformation
events of temporally evolving aggregations.
